GETTING STARTED

Up and running
in a moment.

Summon is a small Windows x64 installer. Download it, run setup, and your launcher is ready from the keyboard.

01 / Install Summon

  1. Download Summon Setup for Windows.
  2. Open the downloaded file and follow the setup steps. Windows may ask you to confirm before running a newly downloaded installer.
  3. If the matching .NET Desktop Runtime is missing, Setup will offer to download and install .NET Desktop Runtime 10 or newer. An internet connection is needed for this step.
Offline install: Install Microsoft's .NET 10 Desktop Runtime x64 separately, then run Summon Setup again.

02 / Open the launcher

Use the Summon shortcut created during setup to launch it. Search by typing an app or file name, then press Enter to open the selected result. Configure its appearance and capabilities from Settings.

03 / AI answers and GIF search

These are optional capabilities. Enable them in Settings → Capabilities, then configure a supported provider. Bring your own key (BYOK): provider credentials are required before /ask or /gif can make requests.

Requests run only when you enter their respective modes.
